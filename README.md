## Quick Start

```bash
# 1. Install dependencies
pip install pandas numpy scikit-learn xgboost lightgbm openpyxl joblib matplotlib

# 2. Place raw Excel files in data/raw/
#    PRAVARTANAM-ADDITIONS_SMS.xlsx
#    Liquid_Steel_Composition.xlsx
#    PRAVARTANAM-HM_ANALYSIS.xlsx

# 3. Run pipeline (clean, merge, feature engineer, split)
python src/pipeline.py

# 4. Train all models
python src/train.py

# 5. Evaluate on test set
python src/evaluate.py

# 6. Predict on a new heat
python src/predict.py --mode predict

# 7. Optimise FA dose for a target chemistry
python src/predict.py --mode optimise --step 50
```

## Models

| Model | Role |
|---|---|
| Linear Regression | Reference baseline |
| Random Forest | Ensemble baseline + feature importance |
| **XGBoost** | **Primary model** |
| LightGBM | Secondary; average with XGBoost for ensemble |

- C is log-transformed (skewness = 5.3) before training; predictions inverse-transformed back.
- Scaler fitted on training data only — no leakage.
- XGBoost + LightGBM ensemble averages predictions for improved stability on minority grades.

## Optimiser

`predict.py --mode optimise` runs a grid search over FeMn / SiMn / FeSi addition space (step size configurable via `--step`) and returns the **minimum total FA dose** that satisfies all target chemistry constraints.

Input: process parameters + target chemistry range JSON.
Output: recommended FeMn, SiMn, FeSi additions + predicted composition.

## Known Limitations

- **Si** weakly correlated with all continuous features (max r = 0.107). Grade encoding is critical; a grade-stratified model is recommended next.
- **High-carbon grades** (R34, ~3% of heats) will be underpredicted. A separate model is recommended.
- **Minority grades** — 64 of 76 grades account for only 23% of heats. Always evaluate per-grade RMSE; overall RMSE alone is misleading.
- **Optimiser** uses grid search — sufficient for FA step sizes of 50 kg but slow at finer resolution. Replace with scipy.optimize or a Bayesian optimiser for production use.
